## ⚖️ Project Spotlight — LexGuard

**An open-source legal learning & case-reference platform** that organizes legal information from official Indian sources into structured, understandable, and traceable records.

> **Collect → Structure → Simplify → Verify → Connect → Reference official sources**

- 🎯 Helps law students, interns, clerks, and citizens understand *where to look, which source is authoritative, and how cases relate* — without pretending to be a lawyer or giving legal advice
- 🗂️ A documented **13-table relational schema** (source provenance, court-learning structure, structured case references) with integrity & review controls
- 🔐 Records **source provenance** and uses **SHA-256 hashing** (via a Python/FastAPI service) to verify source-file integrity — with a clear **review-status lifecycle** (draft → source_linked → metadata_reviewed → file_verified …)
- 🧱 Flow: **Learn → Search → Compare → Verify** (search/comparison/AI-extraction are scoped to later phases; the current Phase 1–3 focus is schema, validation, provenance, seeding & draft quarantine)
- 🛠️ Built with **Python 3.12 · FastAPI · SQLAlchemy · Pydantic · SQLite · Jinja2 · pytest · Uvicorn** — with an emphasis on validated data, tested constraints, and honest, source-backed content
